# 🎓 Student Marks Calculator

A simple web application built using Python and Streamlit to calculate student marks, percentage, grade, and pass/fail status.

## 🚀 Features

- Enter marks for different subjects
- Calculate total marks
- Calculate percentage
- Display grade
- Show Pass/Fail result
- Percentage progress bar
- Simple and clean Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Git
- GitHub
